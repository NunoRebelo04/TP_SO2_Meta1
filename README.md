Placar

Projeto desenvolvido no âmbito de Sistemas Operativos II.

📌 Sobre o projeto

O Placar é uma aplicação desenvolvida em C/C++ utilizando o Visual Studio.

Este projeto faz parte do trabalho TP_SO2_Meta1.

Esta secção pode ser atualizada com uma descrição mais detalhada do objetivo e funcionamento da aplicação.

🛠️ Tecnologias
C / C++
Microsoft Visual Studio
Projeto Visual C++ (.vcxproj)

x64
x86

🚀 Como executar
1. Clonar o repositório
git clone <URL_DO_REPOSITORIO>
2. Abrir o projeto

Abrir o ficheiro:

TP_SO2_Meta1.slnx

no Microsoft Visual Studio.

3. Escolher a arquitetura

Selecionar uma das plataformas disponíveis:

x64

ou

x86
4. Compilar

No Visual Studio:

Build → Build Solution
5. Executar

Depois da compilação, executar o projeto diretamente através do Visual Studio.
